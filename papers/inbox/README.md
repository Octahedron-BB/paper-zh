# papers/inbox —— 手工下载的 PDF 先丢这里

文献速览（`tools/build_digest.py`）只告诉你**该下载哪篇**，不替你下载。

- 把从校园网 / 图书馆下载到的 PDF **原样**丢进这个目录，文件名不用改。
- 手工也完全可以：按速览页面里写的 `doc_id` 改名成 `<doc_id>.pdf`，直接放进 `papers/`。
- （待实现）工具会读 PDF 前两页抽出 DOI，自动认出这是哪一篇，
  随后改名放进 `papers/`，并给出要跑的命令。

⚠️ 本目录下的 PDF 已被 `.gitignore` 里的 `papers/**/*.pdf`（**递归**规则）忽略，
不会被误提交。原文 PDF 因版权原因严禁入库。
